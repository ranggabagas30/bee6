## Split: agent-buildable vs Rangga-only

CLIs (`gcloud`, `firebase`) are now installed locally, but authenticating them requires
Rangga's own Google account (interactive OAuth) and a real billing account — no agent can
do this. So R-01 splits:

### Agent-buildable now (no live GCP needed)
- [ ] Next.js + TypeScript (strict) skeleton: `app/` (screens + API routes), `lib/pipeline/`,
      `lib/agents/`, `config/`, `scripts/` (probe, seed, eval), `docs/` (already exists)
- [ ] `region probe` script (`scripts/probe.ts`): calls each model
      (`gemini-3.5-transcribe`, `gemini-3.5-flash-lite`, `gemini-3.5-flash`, the Live model)
      at asia-southeast2 → asia-southeast1 → global, writes `config/regions.yaml`. Cannot be
      *run* for real until a GCP project + service account exist, but the script itself,
      its retry/error-recording logic, and a unit test with a mocked client can be built now.
- [ ] `cloudbuild.yaml`: build + deploy to Cloud Run `web` in asia-southeast2, wired to trigger
      on push to `main` (the trigger itself has to be created in the GCP console by Rangga,
      but the config file is code)
- [ ] LICENSE file + third-party notices (Silero VAD MIT, ADK Apache-2.0, ONNX Runtime MIT)
- [ ] `.gitignore` (done — blocks audio, `.env*`, `/private/`)
- [ ] Hello-world page + a `/api/health` route as the deploy smoke test

### Rangga-only (needs your Google account / billing)
1. `gcloud auth login` (interactive)
2. Create two GCP projects: `bee6-pilot` (real Proofed data) and `bee6-playground` (demo,
   fictional only) — exact names to confirm with you
3. Link billing to both, set budget alerts at 50/90/100%
4. Enable APIs on both: Agent Platform, Cloud Run, Firestore, Cloud Build, Secret Manager,
   Sensitive Data Protection, Cloud Scheduler, Cloud Tasks
5. Create a service account for `web` (no API keys) with least-privilege roles
6. Create the Cloud Build trigger pointing at the GitHub repo once it exists
7. `firebase login` + link a Firebase project to `bee6-pilot` for Auth

I'll hand you the exact `gcloud`/`firebase` commands for steps 1–7 once the code skeleton is
ready, so you can run them in one pass.
