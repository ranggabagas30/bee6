## 1. Metric definitions (fixed; the report prints them)

- **Episode** = one thread (`threads` doc). Gold label = the human's category for it (one of the 12 `CATEGORIES`,
  including `NON_WORK` if a human judges the whole thread private). Prediction = the thread's stored `category`
  (model output). Rows whose gold cell is empty or `SKIP` are excluded and counted.
- **Confusion matrix:** rows = gold, columns = predicted, over every category that appears in either.
- **Per category c:** precision = TP / (TP + FP), recall = TP / (TP + FN), F1 = harmonic mean; a 0/0 is printed as
  `n/a`, never 0. **Support** = number of gold rows of c, printed next to each.
- **Macro-F1** = mean F1 over categories with support ≥ 1 (categories absent from the gold set are listed, not
  averaged). **Accuracy** printed too.
- **Rush-hour subset:** the same metrics for episodes whose first line starts 11:00–13:59 or 17:00–19:59 outlet-local
  (default windows, §6 Q-2).
- **Agreement:** on episodes labelled by both reviewers (`gold_2` column filled), Cohen's kappa and raw agreement;
  the metrics above use `gold` (reviewer 1) only.
- **Transcribe:** WER = (S + D + I) / N words, after normalising both texts (Unicode NFKC, lower-case, strip
  punctuation except digits, collapse whitespace); reported per clip and pooled (sum of edits / sum of reference
  words). Latency = wall time of each transcribe call; p50/p95 by nearest-rank. $/speech-minute = the per-minute price
  constant `TRANSCRIBE_USD_PER_MIN = 0.0051` (pricing page cited in the pipeline spec "Sources", checked 29 Sept) ×
  minutes; printed as "list price, not billed cost".
- **Sample sizes** printed at the top of every section. No confidence intervals (§6 Q-3).

## 2. Tasks

### Task 1: episode export (0.5 h, `developer`)

New `scripts/eval-export.ts` (`npm run eval:export -- --project <id> --outlet <id> --from YYYY-MM-DD --to YYYY-MM-DD`):
- Refuses the pilot project id unless `--allow-pilot` is passed (for the day the pilot runs); refuses an outlet id
  starting `sbx-`.
- Reads (admin SDK, read-only) `threads` where `outlet_id == X` and `first_line_start_ms` in the range (the existing
  `(outlet_id, first_line_start_ms)` index), field mask `thread_id, category, first_line_start_ms, lines, summary`.
- Writes `private/eval/episodes-<outlet>-<from>-<to>.csv` with columns
  `episode, local_date, start_hm, lines, model_category, gold, gold_2, notes`, where `episode` = `E0001…` in time
  order, `lines` = the stored (already redacted) line texts joined with ` / `, `gold`/`gold_2`/`notes` empty. **No
  thread id or device id in the CSV.** A second file `private/eval/episodes-…-map.csv` maps `episode → thread_id`
  (kept private; the eval never needs it, it is for auditing).
- `model_category` is the stored `category` (never `confirmed_category`).
- Refuses to overwrite an existing file. Prints counts only, never text.
- The `private/` path is gitignored (verify `git check-ignore private/eval/x.csv` in the test setup note).

back as CSV into `private/eval/gold-<date>.csv`.

### Task 2: label metrics (0.75 h, `developer`)

New `lib/eval/metrics.ts` (pure, tested):
```ts
export interface LabelRow { episode: string; start_hm: string; model_category: Category; gold: Category; gold_2: Category | null }
export function parseGoldCsv(text: string): { rows: LabelRow[]; skipped: number; errors: string[] }; // header must match Task 1's; unknown category → error with the episode alias; empty/"SKIP" gold → skipped
export function confusion(rows: readonly LabelRow[]): { labels: Category[]; matrix: number[][] };
export function perCategory(rows): { category: Category; support: number; precision: number | null; recall: number | null; f1: number | null }[];
export function macroF1(per): number | null;
export function accuracy(rows): number | null;
export function inRushHour(start_hm: string, windows = RUSH_WINDOWS): boolean; // ["11:00","13:59"], ["17:00","19:59"]
export function cohensKappa(pairs: readonly [Category, Category][]): number | null;
export function wer(reference: string, hypothesis: string): { edits: number; words: number }; // Levenshtein on normalised word arrays
export function normalizeForWer(text: string): string[];
export function percentile(values: readonly number[], p: number): number | null; // nearest-rank
```
Use a small hand CSV parser that handles quoted fields with commas and `""` escapes (or the dependency already in
`package.json` if one exists; no new dependency without asking). Tests: a 3×3 hand-computed matrix; precision `n/a`
when a category is never predicted; macro-F1 ignores zero-support categories; kappa on a known example (e.g. 0.4
case from a textbook table, computed in the test); WER: identical → 0, one substitution in 4 words → 0.25, empty
hypothesis → all deletions; normalisation removes punctuation and case; percentile p50/p95 on 1..20; CSV with an
embedded comma and quote; unknown category → error naming `E0007`.

## 3. Edge cases

| Case | Behaviour |
|---|---|
| Fewer than 60 labelled episodes | Report runs; `n` stated at the top; README/deck say "n = …, internal fictional speech" |
| A category never appears in gold | Listed with support 0, excluded from macro-F1 |
| A category never predicted | Precision `n/a` |
| Gold cell typo (`COMPLAIN`) | Error naming the episode alias; the run fails (no silent drop) |
| No `gold_2` rows | Agreement section says "not measured (n = 0)" |
| Sheet re-downloaded after edits | New file, new SHA-256; old reports stay reproducible from the old file |
| Thread line text contains a redaction token | Fine; the human labels redacted text, the model labelled redacted text too |
| Pilot data later | `eval:export --allow-pilot` on the pilot project; files stay in `private/` |
